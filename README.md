# Aspiring AI Engineer & B.Tech Student — Personal Portfolio

A clean, modern, and responsive student developer portfolio website built for a first-semester B.Tech student exploring **Python**, **Web Development**, and **Generative AI**.

## Sections Included

1. **Hero Section**: Student introduction, positioning statement, primary CTAs, and an interactive Python Foundation Workbench.
2. **About Me**: Academic profile (1st-semester B.Tech) and core technical interests.
3. **Technical Skills**: Categorized into Programming, Web Development, AI & Emerging Technologies, and Other (with interactive category filters).
4. **Projects**:
   - **Voter Eligibility Calculator** (`Python`)
   - **ATM Management System** (`Python`)
   - **Student Grade Calculator** (`Python`)
   - Includes interactive logic simulators and full Python source code viewers.
5. **Hackathons & Ideathons**: Timeline event cards with expandable slots for future achievements.
6. **Currently Learning**: Ongoing learning tracks across Python, Web Development, Generative AI, Prompt Engineering, AI Fundamentals, and Data Structures & Algorithms.
7. **Future Goals**: Short- and long-term milestones toward becoming an AI Engineer.
8. **Contact & Footer**: Direct placeholders for LinkedIn, GitHub, and Email with one-click copy buttons and an in-app Placeholder Customizer.
